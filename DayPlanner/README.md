# DayPlanner — планировщик задач на день

Небольшая программа для Windows 10/11 на Rust. Панель с задачами спрятана за верхним краем экрана и
выезжает, когда курсор подведён к самому верху, — как строка меню / Центр уведомлений в macOS.

## Возможности

* **Выезд от верхнего края.** Курсор у верхнего края экрана ≈0,15 с — панель плавно выезжает;
  курсор ушёл с панели — плавно прячется.
* **Несколько мониторов.** Панель открывается на том мониторе, у верхнего края которого находится курсор.
  Если мониторы стоят друг над другом, граница между ними краем не считается — панель там не выскакивает.
* **Не мешает перетаскивать окна.** Если зажата левая кнопка мыши (тащите окно к верху экрана, чтобы
  развернуть), панель не открывается — ни во время перетаскивания, ни сразу после отпускания кнопки.
* **Добавить задачу** с датой и временем (часы и минуты), к которым её нужно выполнить.
* **Сделано** и **Удалить** — обе кнопки с подтверждением; кнопка «Да» первые полсекунды неактивна,
  так что случайный двойной клик ничего не подтвердит.
* **Отчёт за день** — `C:\worksheet\Отчет_ГГГГ-ММ-ДД.txt`. Пишется автоматически в 23:59; папка создаётся,
  если её нет. Дата в имени файла, поэтому отчёты разных дней друг друга не перекрывают. Если в полночь
  компьютер был выключен, отчёт за пропущенный день дописывается при следующем запуске.
  Кнопка «Сформировать отчёт сейчас» создаёт отчёт за сегодня в любой момент.
* «Закрепить» — панель не прячется; «Выход» — закрыть программу (с подтверждением).
* **Значок в трее** (область уведомлений): щелчок левой кнопкой открывает панель, в меню по правой
  кнопке — «Открыть планировщик» и «Выход».
* **Запуск заметен.** При запуске вручную панель сама выезжает на несколько секунд; повторный запуск
  ярлыка показывает панель уже работающей программы. При автозапуске с Windows (`--autostart`) появляется
  только значок в трее. Если программа не смогла запуститься, она покажет окно с ошибкой и запишет её в
  `%APPDATA%\DayPlanner\error.log`.

Задачи хранятся в `%APPDATA%\DayPlanner\tasks.json`.

## Установка

Запустите `DayPlanner-Setup-1.0.0.exe`. Права администратора не нужны: программа ставится в
`%LOCALAPPDATA%\Programs\DayPlanner`, добавляется в меню «Пуск» и (по умолчанию) в автозагрузку.
Удаление — через «Приложения» Windows или ярлык «Удалить DayPlanner»; задачи и отчёты при этом остаются.

Установщик и `DayPlanner.exe` собирает GitHub Actions (`.github/workflows/dayplanner.yml`, артефакт
`DayPlanner-Setup`).

## Сборка

```bat
cargo test
cargo build --release
makensis /DVERSION=1.0.0 installer\DayPlanner.nsi
```

Результат: `target\release\DayPlanner.exe` и `dist\DayPlanner-Setup-1.0.0.exe`.

`tests\e2e.ps1` проверяет на настоящей Windows поведение у края экрана (выезд, скрытие, перетаскивание
с зажатой кнопкой) и запись отчёта в `C:\worksheet`.

## Устройство

| Файл | Назначение |
| --- | --- |
| `src/edge.rs` | логика горячего края (задержка, блокировка при перетаскивании) и кривая анимации |
| `src/model.rs` | задачи, хранение в JSON |
| `src/report.rs` | текст отчёта и расписание (23:59, пропущенные дни) |
| `src/platform.rs` | Win32: курсор, кнопка мыши, положение окна |
| `src/ui.rs` | интерфейс (egui) |
| `src/tray.rs` | значок в трее и его меню |
| `assets/icon.ico` | значок exe и установщика (рисуется скриптом `assets/make_icon.py`) |
| `src/main.rs` | запуск и фоновый поток, который двигает панель и пишет отчёты |
