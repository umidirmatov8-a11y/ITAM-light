# Изменения A.R.C.

Формат: для каждой версии — раздел `## X.Y.Z — дата`. Текст раздела становится описанием релиза на GitHub.

## 1.0.0 — 2026-10-12

Первый выпуск: локальный голосовой помощник для Windows 10/11 x64.

### Возможности
- Команды на русском голосом (офлайн, faster-whisper), текстом и жестами (MediaPipe): запуск программ и игр, громкость, окна, файлы, системная информация, сценарии.
- Менеджер разрешений: категории A/B/C, подтверждения, тестовый режим, аварийная остановка (Ctrl+Alt+End), журнал аудита.
- Локальный ИИ через Ollama: понимает свободные фразы, но только предлагает действия из каталога.
- Режим ONLINE: поиск (Википедия, DuckDuckGo, Brave, SearXNG) с кратким ответом и ссылками; в режиме LOCAL — ни одного запроса в интернет.
- Документы PPTX / DOCX / XLSX / PDF / TXT с проверкой файла после создания.
- Модули `.arcplugin`: подписанные описания команд без кода, с отдельными разрешениями.

### Установка
Скачайте `ARC-Setup-1.0.0.exe`, при желании сверьте SHA-256 с файлом `.sha256`. Установщик без цифровой подписи: SmartScreen → «Подробнее» → «Выполнить в любом случае». Подробно — `ARC/docs/INSTALL.md`.

### Известные ограничения
- Нет коммерческого сертификата подписи кода.
- Проверено в Windows CI без микрофона, камеры и GPU; на реальном оборудовании с RTX 4060 Ti не проверялось.
