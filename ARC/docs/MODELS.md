# Локальные модели

A.R.C. **никогда не скачивает модели сам**. Всё ниже — по вашему решению.

## Ollama (локальный ИИ)

Используется, когда встроенный разбор не понял фразу («на экране бардак, убери всё», «мне надо кое-что
посчитать») или программа не найдена по названию, а также для ответов на общие вопросы. Модель **только
предлагает** действия из каталога — см. [SECURITY.md](SECURITY.md).

1. Установите Ollama: <https://ollama.com/download> (отдельно от A.R.C.).
2. Загрузите модель:
   ```powershell
   ollama pull qwen2.5:7b          # ≈4,7 ГБ — рекомендуется для русского
   ```
   `qwen2.5-coder:7b` (значение по умолчанию) тоже работает, но обычная `qwen2.5:7b` лучше понимает разговорный русский.
3. «Настройки → Локальная модель»: адрес `http://127.0.0.1:11434`, модель, «Проверить подключение».
4. Переключатели: «Разбирать непонятные фразы моделью», «Отвечать на общие вопросы»,
   «Подтверждать каждое действие, предложенное моделью» (для осторожных).

| Оборудование | Модель | Время ответа |
|---|---|---|
| RTX 4060 Ti 8 ГБ | `qwen2.5:7b` (Q4) целиком в видеопамяти | 1–3 с |
| без дискретной GPU | `qwen2.5:3b` (≈2 ГБ) | 5–20 с на CPU |

Без Ollama A.R.C. работает как раньше: встроенный разбор команд, голос и жесты от модели не зависят.
Адрес Ollama вне этого компьютера считается внешним сервисом и используется только в режиме ONLINE.

## Распознавание речи (Whisper)

Загрузка: «Настройки → Локальные модели → Загрузить» (размер показывается до загрузки, нужно подтверждение).
Источник — HuggingFace (`Systran/faster-whisper-*`), после загрузки работает полностью офлайн.
Файлы: `%LOCALAPPDATA%\ARC\models\<модель>`.

| Модель | Размер | RTX 4060 Ti (CUDA) | CPU (8 ядер) | Комментарий |
|---|---|---|---|---|
| `whisper-tiny` | 75 МБ | < 0,3 с | ~0,5 с | много ошибок в русском |
| `whisper-base` | 145 МБ | < 0,3 с | ~1 с | приемлемо для коротких команд |
| `whisper-small` | 484 МБ | ~0,4 с | 2–4 с | **рекомендуется** |
| `whisper-medium` | 1,5 ГБ | ~0,8 с | 6–12 с | лучшее качество, нужна GPU |

«Вычисления → Автоматически» использует CUDA, если она доступна, иначе CPU (int8).
Для CUDA нужны библиотеки cuBLAS 12 и cuDNN 9 (ставятся с CUDA Toolkit 12 или пакетами NVIDIA);
без них A.R.C. сам переключится на CPU и сообщит об этом в «Диагностике».

Чтобы точнее распознавать названия программ, A.R.C. подсказывает модели имена из вашего реестра приложений.

## Озвучка ответов

| Движок | Загрузка | Комментарий |
|---|---|---|
| **Windows (SAPI)** — по умолчанию | не нужна | Русский голос («Microsoft Irina») входит в языковой пакет ru-RU: «Параметры → Время и язык → Речь → Добавить голоса». |
| **Piper** | программа 22 МБ + голос 63 МБ | Естественный нейросетевой голос (Ирина, Дмитрий, Денис). Запускается как отдельная программа `piper.exe` (MIT). |
| Не озвучивать | — | Ответы только на экране. Режим тишины тоже отключает озвучку. |

Лицензии: faster-whisper, CTranslate2, PortAudio, Piper — MIT. Python-пакет `piper-tts` (GPL) в A.R.C.
не встраивается: используется отдельный исполняемый файл Piper.

## Распознавание рук (жесты)

| Модель | Размер | Источник | Лицензия |
|---|---|---|---|
| MediaPipe Hand Landmarker (float16) | 8 МБ | Google Storage (`mediapipe-models/hand_landmarker`) | Apache 2.0 |

Модель находит 21 точку руки; сам жест определяет A.R.C. по углам суставов и расстояниям (устойчиво к повороту
и масштабу). Работает на CPU, ~15 кадров/с при 640×480 достаточно.
