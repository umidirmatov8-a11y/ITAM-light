## Этап 2 — голос

* `VoiceEngine`: захват (sounddevice/WASAPI), VAD, faster-whisper (CPU int8 / CUDA float16), язык ru.
* Push-to-talk (Ctrl+Alt+Space), постоянное прослушивание со словом активации, отключение микрофона.
* Piper для ответов (голос, скорость, громкость; молчит в режиме тишины).
* Оценка уверенности → `Assistant.handle_text(text, Source.VOICE, confidence)` (порог и wake word уже реализованы).
* Загрузка моделей только по согласию, с размером и проверкой места. Тест офлайн-работы.

## Этап 3 — камера и жесты

* `VisionEngine`: OpenCV + MediaPipe Hands, отдельный процесс, без сохранения кадров.
* Калибровка, порог уверенности, удержание, антидребезг, пауза между командами.
* Переназначаемые жесты → только действия с `gesture_allowed` и риском A (проверка уже в Permission Manager).

## Этап 4 — локальный ИИ

* Неизвестная роутеру фраза → Ollama с JSON-схемой ответа: список действий **из каталога**.
* План модели проходит тот же Permission Manager (`Source.AI`: B/C — всегда подтверждение,
  смена режима запрещена). Ответы модели в shell не попадают.

## Этап 5 — интернет и документы

* Online Research Engine: подключаемые провайдеры поиска, тайм-ауты, лимит запросов, ключи в DPAPI.
* Document Engine: python-pptx, python-docx, openpyxl, PDF; структура — локально, факты — после
  отдельного веб-поиска; проверка созданного файла перед ответом «готово».

## Этап 6 — завершение

* Plugin Manager (подписанные манифесты модулей, отдельные разрешения), офлайн-тесты, аудит безопасности,
  подпись установщика.
