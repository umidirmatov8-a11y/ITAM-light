# Установка A.R.C.

## Требования

* Windows 10/11 x64. Права администратора для установки **не нужны** (установка в профиль пользователя).
* ~0,5 ГБ на диске для приложения. Локальные модели — отдельно (см. [MODELS.md](MODELS.md)).
* Интернет не нужен. Ollama не обязательна: без неё работают все системные команды.

Проверка окружения (ничего не устанавливает):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\check_env.ps1
```

## Установка

1. Запустите `ARC-Setup-<версия>.exe`.
2. Выберите «только для меня» (рекомендуется) или «для всех пользователей» (потребуется UAC) и каталог.
3. Ярлыки «A.R.C.» создаются в меню «Пуск» и на рабочем столе.

Тихая установка: `ARC-Setup-0.1.0.exe /S` (по умолчанию `%LOCALAPPDATA%\Programs\ARC`),
в свой каталог: `ARC-Setup-0.1.0.exe /S /D=D:\Apps\ARC` (`/D` — последним параметром, без кавычек).

## Первый запуск

1. A.R.C. открывает пульт; ядро стартует за 1–3 с (индикатор «ядро» в заголовке).
2. **Приложения → Найти установленные** — импорт из меню «Пуск», Steam, Epic Games, Microsoft Store.
   Ничего не запускается при поиске; записи можно удалить из реестра, программа при этом не удаляется.
3. **Разрешения**: проверьте разрешённые каталоги (по умолчанию «Рабочий стол», «Документы», «Загрузки»).
   **Тестовый режим** включён: операции категорий B/C (создание папок, завершение процессов, выключение)
   только записываются в журнал. Выключите его, когда убедитесь, что всё работает как ожидается.
4. **Настройки → Запускать вместе с Windows** — автозапуск свёрнутым в трей.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+A | показать / скрыть A.R.C. |
| Ctrl+Alt+End | аварийная остановка автоматизации (работает при скрытом окне) |
| ↑ / ↓ в терминале | предыдущие команды |

Закрытие окна сворачивает A.R.C. в трей; выход — меню трея «Выход».

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки, реестр, сценарии, история, журнал | `%LOCALAPPDATA%\ARC\arc.db` (SQLite) |
| Логи ядра | `%LOCALAPPDATA%\ARC\logs\backend.log` |
| Положение окна, масштаб, логи интерфейса | `%APPDATA%\ARC\` |

Видео и аудио не сохраняются. Телеметрия не собирается.

## Удаление

«Параметры → Приложения → A.R.C. → Удалить» или `Uninstall ARC.exe /S`. Данные пользователя
сохраняются; чтобы удалить и их, удалите каталоги `%LOCALAPPDATA%\ARC` и `%APPDATA%\ARC`.

## Сборка из исходников

Нужны Python 3.12+, Node.js 20+ (LTS).

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
# результат: app\release\ARC-Setup-<версия>.exe
```

Скрипт создаёт `backend\.venv`, ставит зависимости из `backend\requirements*.txt` (версии зафиксированы),
прогоняет pyflakes и pytest, собирает ядро PyInstaller и проверяет `arc-backend.exe --selftest`, затем
`npm ci`, проверку типов, vitest, сборку Vite и установщик electron-builder. Ключ `-SkipTests` пропускает тесты.
