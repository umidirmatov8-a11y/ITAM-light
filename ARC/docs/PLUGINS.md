# Модули (.arcplugin)

Модуль добавляет голосовые и текстовые фразы, которые выполняют действия из каталога A.R.C.
Это **описание, а не программа**: в модуле нет кода, поэтому установить «вирус» в виде модуля нельзя.

## Что можно и чего нельзя

* Можно: действия категорий A и B (громкость, окна, запуск программ из реестра по имени, системная
  информация, поиск и открытие файлов в разрешённых каталогах, создание папок и документов, сайты,
  поиск в интернете в режиме ONLINE, сценарии).
* Нельзя: выключение/перезагрузка, смена LOCAL/ONLINE, запуск от администратора, завершение процессов
  по номеру, выполнение команд или скриптов, изменение настроек и разрешений.
* Встроенные команды важнее: модуль не может перехватить «сверни все окна» или «выключи компьютер».
* Действия категории B требуют вашего подтверждения, как и обычные команды.

## Установка

1. «Модули → Доверенные ключи авторов»: добавьте публичный ключ автора (сверьте с источником).
2. «Модули → Установить модуль…» → выберите файл `.arcplugin`.
3. Модуль установлен **выключенным и без разрешений**: включите нужные разрешения и сам модуль.

Модуль, подписанный неизвестным ключом, или изменённый после подписи, не устанавливается. Неподписанные
модули разрешаются только явно (для разработки своих модулей). Обновление — только более новой версией,
подписанной тем же ключом; новые разрешения после обновления выключены.

## Как сделать свой модуль

Пример описания — [plugins/example-evening.json](plugins/example-evening.json).

```powershell
cd backend
.venv\Scripts\python -m arc_backend.plugins.tool keygen --out my-key.pem      # один раз; ключ храните в секрете
.venv\Scripts\python -m arc_backend.plugins.tool check ..\docs\plugins\example-evening.json
.venv\Scripts\python -m arc_backend.plugins.tool sign ..\docs\plugins\example-evening.json --key my-key.pem --out evening-mode.arcplugin
.venv\Scripts\python -m arc_backend.plugins.tool verify evening-mode.arcplugin --public-key <публичный ключ>
```

Поля описания: `format` (1), `id` (латиница, цифры, дефис), `name`, `version` (`1.2.3`), `author`,
`description`, `homepage` (https), `permissions` (модули: `apps`, `volume`, `windows`, `system_info`,
`files`, `processes`, `browser`, `web_search`, `scenarios`, `documents`), `commands` — до 50 команд:
`phrases` (до 20 фраз), `actions` (до 5 действий каталога с параметрами; для программ — `"app": "Имя"`
вместо `app_id`), `reply` (ответ перед результатом). Подпись — Ed25519 над каноническим JSON описания.
