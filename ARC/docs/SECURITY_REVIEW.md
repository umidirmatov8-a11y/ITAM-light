# Аудит безопасности (этап 6)

Проверка всего кода A.R.C. 1.0.0 перед выпуском. Для каждой найденной проблемы есть исправление и
регрессионный тест (`backend/tests/test_security_review.py`, `test_plugins.py`, `test_offline.py`).

## Что проверялось

## Находки и исправления

1. **Формулы в CSV-экспорте журнала (средняя).** Текст команд, страниц и ответов модели попадал в CSV
   как есть; ячейка `=HYPERLINK(...)` или `=cmd|...` при открытии в Excel выполняется как формула.
   Исправлено: ячейки, начинающиеся с `= + - @`, табуляции или CR, экранируются апострофом (`csv_cell`).
2. **Промежуточное перенаправление на http (низкая).** Клиент проверял только конечный адрес после
   автоматических перенаправлений, поэтому промежуточный запрос мог уйти по http. Исправлено:
   перенаправления обрабатываются вручную (не больше 3), каждый адрес проверяется до запроса.
3. **Неполный список опасных типов файлов (средняя).** «Открыть файл» не открывает исполняемые файлы, но в
   списке не было документов с макросами (`.docm`, `.xlsm`, `.pptm`…), `.chm`, `.msc`, `.iso/.vhdx`,
   `.settingcontent-ms`, `.appref-ms`, `.library-ms`, `.scf`, `.theme`, `.xll`, `.one` и др. Исправлено.
4. **Пароль сертификата в логе при ошибке подписи (низкая).** Общая функция запуска печатала все аргументы
   при ошибке. Исправлено: `signtool` вызывается отдельно, сообщение об ошибке без аргументов; в CI пароль
   временного сертификата маскируется.

## Модули (новое на этапе 6)

Модуль — только JSON-описание; кода в нём нет и выполнить его нельзя. Проверки: подпись Ed25519 ключом из
списка доверенных (подмена любого байта описания обнаруживается), неподписанные — только после явного
разрешения, действия только A/B из каталога (не `power`, не `modes`, не `process.terminate`,
не `app.launch_admin`), каждое разрешение пользователь включает отдельно, встроенные команды важнее,
обновление — только более новой версией и тем же ключом, Permission Manager отдельно запрещает источнику
«модуль» действия C. Удаление ключа из доверенных сразу выключает подписанные им модули.

## Остаточные риски (принимаются)

* Вредоносная программа, уже работающая под тем же пользователем Windows, может читать память A.R.C. и
  вызывать локальный API, если украдёт токен из памяти Electron. Защита рассчитана на браузеры, другие
  учётные записи и сеть.
* Без коммерческого сертификата установщик не подписан и SmartScreen предупреждает (см. [SIGNING.md](SIGNING.md)).
* Качество разбора фраз маленькой локальной моделью ограничено; ошибки модели не опасны, потому что всё
  проходит каталог и подтверждения, но модель может предложить «не ту» безопасную программу.
* DuckDuckGo HTML может менять разметку — тогда поиск продолжается через Википедию/Brave/SearXNG.
