# Устранение неполадок

Начните с «Диагностика → Проверить снова → Сохранить отчёт» и логов:
`%LOCALAPPDATA%\ARC\logs\backend.log`, `%APPDATA%\ARC\logs\main.log`.

| Симптом | Причина и решение |
|---|---|
| Баннер «Ядро недоступно», индикатор «ядро» красный | Ядро упало 5 раз подряд. Откройте `backend.log`, нажмите «Перезапустить ядро». Антивирус может блокировать `resources\backend\arc-backend.exe` — добавьте каталог установки в исключения. |
| «Не найден исполняемый файл ядра» | Установка повреждена — переустановите A.R.C. |
| «Не нашёл программу … в реестре» | «Приложения → Найти установленные» или «Добавить». Добавьте псевдоним («телега», «стим»). |
| «Файл … не найден» при запуске | Программа перемещена/удалена. Исправьте путь в реестре. |
| «Программа требует прав администратора» | Включите у записи «От имени администратора» (каждый запуск подтверждается + UAC). |
| «уже запущен», но окно не появилось | Windows запрещает выводить окна поверх при активном полноэкранном приложении. Переключитесь вручную. |
| Громкость меняется шагами по 2 % | Не загрузился pycaw (см. «Диагностика → Громкость»); используется медиаклавиша. |
| «Не найдено устройство вывода звука» | Нет активного устройства воспроизведения: «Параметры → Звук → Вывод». |
| «[ТЕСТОВЫЙ РЕЖИМ] Действие не выполнено» | Так и задумано на первом этапе. «Разрешения → Тестовый режим» — выключить. |
| «Путь вне разрешённых каталогов» | «Разрешения → Разрешённые каталоги → Добавить каталог». |
| «Для этого нужен режим ONLINE» | Скажите/введите «переключись в онлайн-режим» или переключатель «Сеть» на пульте. |
| «Онлайн-функции полностью отключены» | «Настройки → Сеть → Разрешить онлайн-функции». |
| «Поиск не удался: … Нет связи с сервером» | Нет интернета, прокси или брандмауэр блокирует A.R.C. (`arc-backend.exe`). Системный прокси из переменных `HTTPS_PROXY` учитывается. |
| «DuckDuckGo попросил подтвердить, что запрос от человека» | Сервис временно ограничил запросы. Включите Википедию/Brave/SearXNG в «Настройки → Интернет» или подождите. |
| «Превышен лимит: N запросов в минуту» | Защита от лишних запросов. Подождите минуту или увеличьте лимит в «Настройки → Интернет». |
| «Сервис отказал в доступе (HTTP 401/403)» | Неверный ключ Brave Search API — введите заново в «Настройки → Интернет». |
| Ответ без краткой сводки | Сводку пишет локальная модель: запустите Ollama или выключите «Краткий ответ по найденному». |
| Документ — «шаблон» | Локальная модель недоступна или вернула неверную структуру (см. предупреждение у задания). Запустите Ollama; для качества — `qwen2.5:7b`. |
| «Чтобы собрать факты в интернете, нужен режим ONLINE» | Переключитесь в ONLINE или попросите документ без «с данными из интернета». |
| «Не найдена папка «Документы»» / «Путь вне разрешённых каталогов» | Укажите папку в «Настройки → Документы» внутри разрешённых каталогов («Разрешения»). |
| «Не найден шрифт с кириллицей» (PDF) | В Windows нужен Arial или Segoe UI (стандартные шрифты). Восстановите шрифты Windows. |
| «Файл не прошёл проверку» | Файл после записи не совпал с содержимым и удалён. Повторите; если повторяется — отчёт из «Диагностики» и `backend.log`. |
| Ollama «не запущена» | Запустите Ollama (значок в трее) или `ollama serve`; проверьте адрес. Системные команды работают и без неё. |
| Ollama «нет модели» | `ollama pull <модель>` или укажите установленную модель в настройках. |
| «Не понял команду. Ollama недоступна» | Встроенный разбор не понял фразу, а локальная модель не запущена. Запустите Ollama или переформулируйте («что ты умеешь» — примеры). |
| «Локальная модель не ответила за N с» | Модель слишком большая для CPU: возьмите `qwen2.5:3b` или увеличьте тайм-аут. |
| Модель предлагает не то | Возьмите `qwen2.5:7b`; включите «Подтверждать каждое действие, предложенное моделью»; добавьте псевдонимы приложениям. |
| GPU «N/A» | Нет драйвера NVIDIA / `nvidia-smi`. На работу команд не влияет. |
| Кнопка «Голос» неактивна, «нет модели речи» | «Настройки → Локальные модели» → загрузите Whisper (рекомендуется small). |
| «Микрофон не найден» / «Не удалось открыть микрофон» | Подключите микрофон; «Конфиденциальность → Микрофон → Разрешить классическим приложениям»; выберите устройство в «Настройки → Голос». |
| «Речь не услышана» | Чувствительность выше; проверьте уровень записи в Windows; на осциллографе должен быть заметный сигнал. |
| Фразу обрывает | Увеличьте «Паузу конца фразы». |
| «Не расслышал команду» | Говорите ближе к микрофону; модель small/medium вместо tiny/base; снизьте порог уверенности в «Общих». |
| В режиме постоянного прослушивания ничего не выполняется | Команда должна начинаться со слова активации («АРК, …»). |
| Распознавание медленное | Без CUDA модель работает на CPU: используйте small или base. Для GPU нужны cuBLAS 12 / cuDNN 9 («Диагностика → Распознавание речи»). |
| A.R.C. не говорит | Включён режим тишины или «Не озвучивать»; для SAPI установите русский голос (см. [MODELS.md](MODELS.md)); «Проверить голос» покажет ошибку. |
| Загрузка модели: «Онлайн-функции отключены» | «Настройки → Сеть → Разрешить онлайн-функции» (нужно только на время загрузки). |
| «Нет модели рук» | «Настройки → Локальные модели → Распознавание рук» → Загрузить (8 МБ). |
| «Камера не найдена или занята» | Закройте программы, использующие камеру (Zoom, Teams, браузер); «Конфиденциальность → Камера»; «Найти камеры» и выберите другую. |
| Жест не срабатывает | «Проверка камеры»: рука целиком в кадре? уверенность выше порога? Добавьте свет; держите жест дольше; снизьте порог уверенности. |
| Жест срабатывает случайно | Повысьте порог уверенности и время удержания; выполните калибровку; поставьте на паузу открытой ладонью. |
| Жесты не реагируют | Пауза (на пульте «жесты на паузе») — покажите открытую ладонь или нажмите «Продолжить». |
| «Это действие нельзя выполнить жестом» | Так задумано: жестам доступны только безопасные действия категории A. |
| Горячая клавиша не срабатывает | Сочетание занято другой программой (см. `main.log`: «shortcut … is taken»). |
| «Автоматизация остановлена (аварийная остановка)» | Кнопка «Снять аварийную остановку» на пульте или в «Разрешениях». |
| Окно «пропало» | Оно в трее: щелчок по значку A.R.C. или Ctrl+Alt+A. |
| Сброс всех настроек | Закройте A.R.C. (трей → Выход) и удалите `%LOCALAPPDATA%\ARC\arc.db`. |
| «Модуль подписан неизвестным ключом» | Добавьте публичный ключ автора в «Модули → Доверенные ключи» (сверьте ключ с источником) и установите снова. |
| «Подпись модуля не сходится» | Файл изменён после подписания — не устанавливайте его, скачайте заново у автора. |
| «Модулю … не выдано разрешение …» | «Модули» → включите нужное разрешение у модуля. |
| Фраза модуля не срабатывает | Модуль выключен или встроенная команда A.R.C. с похожей фразой имеет приоритет — измените фразу в модуле. |
| SmartScreen «Неизвестный издатель» | Установщик не подписан (нет сертификата). Проверьте SHA-256 ([SIGNING.md](SIGNING.md)) → «Подробнее» → «Выполнить в любом случае». |
