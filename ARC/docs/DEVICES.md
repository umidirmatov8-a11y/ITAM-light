# Микрофон и камера

> Переключатели «Микрофон» и «Камера» выключают устройство полностью: A.R.C. его не открывает,
> а уже открытое закрывает в течение секунды.

## Микрофон

1. «Параметры Windows → Конфиденциальность и защита → Микрофон»: включите «Доступ к микрофону» и
   «Разрешить классическим приложениям доступ к микрофону».
2. «Параметры → Система → Звук → Ввод»: выберите устройство, проверьте индикатор громкости.
3. Уровень записи 70–90 %, отключите «Улучшения звука», если речь искажается.
4. `scripts\check_env.ps1` покажет найденные устройства записи и запрет доступа в настройках приватности.

### Как пользоваться

* **Нажать и говорить**: кнопка «Голос» на пульте, кнопка микрофона в виджете или **Ctrl+Alt+Space** в любой
  программе → скажите команду → после паузы ~0,8 с A.R.C. распознает и выполнит её. Повторное нажатие
  завершает фразу сразу. Слово «АРК» здесь не нужно — нажатие уже является явной активацией.
* **Слушать постоянно**: микрофон открыт, но выполняются только фразы, начинающиеся со слова активации
  («АРК, открой Telegram»). Фоновые разговоры игнорируются.
* Фразы с уверенностью ниже порога (по умолчанию 50 %) не выполняются: после нажатия A.R.C. попросит повторить,
  в режиме постоянного прослушивания — промолчит.
* Пока A.R.C. говорит, микрофон не слушает (не реагирует на собственный голос).
* Подтверждение действий категории B можно сказать голосом («да» / «нет»); категории C — только в окне.

Микрофон открывается только во время прослушивания (индикатор «микрофон открыт» на пульте). Аудио обрабатывается
в памяти и никуда не сохраняется и не отправляется.

### Настройка (Настройки → Голос)

* «Микрофон» — конкретное устройство, если по умолчанию выбран не тот.
* «Чувствительность» — выше, если A.R.C. не слышит тихую речь; ниже, если реагирует на шум.
* «Пауза конца фразы» — увеличьте, если A.R.C. обрывает фразу на полуслове.
* Осциллограф на пульте показывает реальный уровень сигнала во время прослушивания.

## Камера и жесты

### Подготовка

1. «Конфиденциальность и защита → Камера»: разрешите доступ классическим приложениям.
2. «Настройки → Локальные модели → Распознавание рук» — загрузите модель MediaPipe (8 МБ, один раз).
3. «Настройки → Жесты: камера» → «Камера разрешена» → «Найти камеры» → выберите камеру.
4. «Проверка камеры» — изображение с наложенным скелетом руки, распознанный жест, уверенность, частота кадров.
   Изображение видно только в этом окне, не сохраняется и закрывается само через 2 минуты.
5. «Калибровка» — покажите открытую ладонь на обычном расстоянии на 3 секунды. После этого руки заметно дальше
   (например, люди за спиной) игнорируются; A.R.C. также предупредит о слабом освещении.

Освещение спереди, рука целиком в кадре, 40–80 см от камеры. Если рук в кадре несколько, команды подаёт ближайшая.

### Жесты по умолчанию

| Жест | Действие | Комментарий |
|---|---|---|
| Открытая ладонь (удержать) | пауза / возобновление жестов | на паузе работает только этот жест |
| Кулак | отменить текущий вопрос или запрос подтверждения | |
| Указательный палец вверх | переключить вид: пульт ↔ компактный виджет | |
| «OK» | режим тишины вкл/выкл | |
| Ладонь в зоне (правый верхний угол кадра, удержать 1,5 с) | свернуть все окна | зона показана на схеме руки |
| Большой палец вверх | повторить последнее безопасное действие | выключен по умолчанию |
| Два пальца (V) | выключить звук | выключен по умолчанию |

Все жесты переназначаются в «Настройки → Жесты: действия». Доступны только безопасные действия категории A
(громкость, окна, запуск приложения из реестра, сценарии, системная информация и т. п.). Удалить файлы,
выключить компьютер, запустить что-то от администратора или подтвердить такую операцию жестом невозможно:
это проверяется и при сохранении настроек, и при каждом срабатывании (Permission Manager, источник «жест»).

### Защита от ложных срабатываний

* жест должен удерживаться (по умолчанию 0,6 с) с уверенностью не ниже порога (70 %);
* тот же жест повторно срабатывает только после того, как рука его «отпустила», и не чаще, чем раз в 1,5 с;
* между любыми командами — пауза не меньше 0,8 с;
* короткие сбои трекинга (до 0,2 с) не сбрасывают удержание;
* аварийная остановка блокирует и жесты.

Кадры обрабатываются только в памяти, ничего не записывается на диск и не отправляется в сеть.
