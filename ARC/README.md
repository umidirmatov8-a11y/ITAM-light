# A.R.C. — Adaptive Responsive Computer

Локальный ретрофутуристический помощник для Windows 10/11 x64: команды на русском языке,
запуск программ и игр, громкость, окна, системная информация, поиск файлов, сценарии —
**без интернета и без облачной подписки**. Опасные операции проходят через менеджер разрешений.

> Статус: **этапы 1–5 готовы** — голосовые и текстовые команды на русском (офлайн, faster-whisper),
> жесты через камеру (MediaPipe), разбор свободных фраз локальной моделью (Ollama), поиск в интернете
> в режиме ONLINE, создание презентаций/документов/таблиц/PDF, реестр приложений, безопасный обработчик
> команд, настройки, журнал, установщик. Дальше — модули и подпись (этап 6): [docs/ROADMAP.md](docs/ROADMAP.md).

## Возможности

* **Голос офлайн**: нажать и говорить (Ctrl+Alt+Space) или постоянное прослушивание со словом «АРК»;
  распознавание faster-whisper на GPU/CPU, озвучка ответов (Windows SAPI или Piper), порог уверенности.
* **Жесты**: открытая ладонь — пауза, кулак — отмена, указательный вверх — пульт/виджет, «OK» — режим тишины,
  ладонь в зоне — свернуть окна; всё переназначается, но только на безопасные действия. Калибровка, проверка камеры.
* **Локальный ИИ** (Ollama, по желанию): понимает свободные формулировки («на экране бардак, убери всё»),
  отвечает на вопросы; только предлагает действия из каталога, которые проходят проверку и подтверждение.
* **Документы**: «сделай презентацию про солнечную систему», «создай документ про историю Рима в формате PDF»,
  «сделай таблицу курсов валют с данными из интернета» → PPTX / DOCX / XLSX / PDF / TXT в «Документы\ARC».
  Текст пишет локальная модель (без неё — размеченный шаблон), факты — только из отдельного поиска; файл
  открывается заново и проверяется, существующие файлы не перезаписываются. «Открой последний документ».
* **Интернет только в ONLINE**: «найди в интернете что такое кубит» — поиск в Википедии и DuckDuckGo
  (по желанию Brave Search API с ключом в диспетчере учётных данных Windows или свой SearXNG), краткий ответ
  локальной модели со ссылками на источники, лимит запросов в минуту, тайм-ауты, журнал каждого запроса.
* Команды на естественном русском языке (голосом или текстом): «открой Telegram», «запусти игру» →
  «Какую игру запустить?» → «Cyberpunk», «увеличь громкость на двадцать процентов», «выключи звук»,
  «сверни все окна», «открой проводник», «найди файл с отчётом на рабочем столе», «какие программы
  сейчас запущены?», «сколько свободного места на диске?», «создай папку Проект», «переключись в режим
  тишины», «переключись в онлайн-режим», «повтори», «отмени», «аварийная остановка».
* Реестр приложений: ручное добавление (EXE/ярлык/UWP/протокол, аргументы, псевдонимы, категории,
  запуск от администратора через UAC), автоматический поиск в меню «Пуск», Steam, Epic Games, Microsoft Store.
  Статус запуска: запущено / уже работает (окно выводится на передний план) / не найдено / запрещено / ошибка.
* Сценарии («рабочий режим», «режим концентрации», свои): последовательности безопасных действий.
* Менеджер разрешений: категории риска A/B/C, подтверждения с тайм-аутом, отключение модулей,
  разрешённые каталоги, тестовый режим (имитация B/C), аварийная остановка (Ctrl+Alt+End), журнал аудита.
* Режимы LOCAL / ONLINE с главным выключателем онлайн-функций; проверка Ollama.
* Интерфейс: пульт с ядром A.R.C., осциллографом, телеметрией CPU/RAM/GPU, терминалом, историей,
  быстрым запуском; компактный плавающий виджет; трей; темы «янтарь/фосфор/лёд», масштаб, отключение анимации.

## Быстрый старт (пользователь)

1. Скачайте `ARC-Setup-<версия>.exe` (артефакт CI «ARC-Setup» или собранный локально) и запустите.
2. Откройте A.R.C. из меню «Пуск» → «Приложения» → **Найти установленные**.
3. «Настройки → Локальные модели» → загрузите `Whisper small` (484 МБ, один раз).
4. Нажмите **Ctrl+Alt+Space** и скажите «открой Telegram» — или введите это в терминале на пульте.

## Разработка

```powershell
powershell -ExecutionPolicy Bypass -File scripts\check_env.ps1 -Dev   # проверка окружения
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1              # запуск с горячей перезагрузкой
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1 -Mock        # то же, но системные действия имитируются
powershell -ExecutionPolicy Bypass -File scripts\build.ps1            # тесты + установщик app\release\ARC-Setup-*.exe
```

Тесты по отдельности:

```powershell
cd backend; .venv\Scripts\python -m pytest tests -q     # ~260 тестов (часть — только на Windows / с моделями)
cd app; npm test; npm run typecheck                      # 18 тестов интерфейса
app\release\win-unpacked\ARC.exe --smoke-test=smoke.json  # сквозная проверка Electron → IPC → backend
```

| Компонент | Технологии |
|---|---|
| Интерфейс | Electron 43, React 19, TypeScript 5.9, Vite 7, собственная CSS-дизайн-система, шрифт IBM Plex Mono (встроен) |
| Ядро | Python 3.12, FastAPI/uvicorn (только 127.0.0.1), pydantic, SQLite, psutil, pycaw/comtypes |

| Локальный ИИ | Ollama `/api/chat` со structured outputs (JSON-схема), строгая валидация плана |
| Сборка | PyInstaller (onedir), electron-builder (NSIS) |
| CI | `.github/workflows/arc.yml` — Windows: тесты, сборка, голос/жесты на реальных моделях, установка/удаление; отдельная задача с реальной Ollama |
