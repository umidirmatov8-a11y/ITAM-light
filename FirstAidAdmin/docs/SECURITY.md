# Политика безопасности

* Принцип наименьших привилегий: основное приложение — `asInvoker`; повышение только через стандартный UAC и `FirstAidAdmin.Helper.exe`.
* Helper выполняет одну операцию из каталога (`RemediationCatalog`), параметры проверяются (службы — белый список, диск — `X:`), имя файла результата — `faa-<guid>.json`.
* Нет обхода UAC/ACL/AV, нет извлечения учётных данных и токенов, нет persistence, скрытого удалённого доступа и backdoor.
* Никаких изменений без подтверждения; CLI изменений не выполняет вообще.
* Пробный запуск программы в сценарии «Не работает программа» — только при явном разрешении.
* Экспорт: маскирование пользователя (по умолчанию), компьютера, домена, IP (по настройке) и секретов (всегда).
* Не собираются: пароли, cookies, токены, содержимое документов и почты.
* Нет телеметрии и сетевых вызовов, кроме диагностических проверок (ping/TCP/DNS/HTTP NCSI) к настраиваемым адресам.
