# AD Admin Toolkit

Настольное Windows-приложение (EXE) для системного администратора Active Directory: просмотр, поиск, диагностика,
аудит и безопасное администрирование пользователей, компьютеров, групп и OU через LDAP.

**Стек:** Python 3.12 · PySide6 · ldap3 · SQLite · openpyxl · PyInstaller. PowerShell не используется
(журналы событий — штатный `wevtutil.exe`).

## Возможности

* Подключение по **LDAPS / StartTLS** с обязательной проверкой сертификата; Simple, NTLM или Kerberos (текущий
  пользователь Windows). Пароль никогда не передаётся по незашифрованному каналу. Автообнаружение домена, DC, Base DN,
  NetBIOS, политики паролей; проверка прав учётной записи; переподключение; тайм-ауты.
* **Главная**: точная статистика домена с временем сбора и ошибками; приблизительные значения помечены.
* **Пользователи**: 17 представлений (отключённые, заблокированные, истёкшие, PNE, «запрет смены пароля» по ACL,
  неактивные, неполные атрибуты, привилегированные…), поиск и фильтры, карточка с группами и путями вложенности,
  точный lastLogon по всем DC; включение/отключение, разблокировка, сброс пароля, атрибуты, срок действия,
  перемещение, группы, создание по шаблону и копированием, обработка уволенных.
* **Компьютеры**, **группы** (вложенность, косвенное членство, пустые группы с учётом primaryGroupID, защита
  привилегированных групп), **структура OU** (счётчики, пустые OU, снимки и сравнение «до/после»).
* **Аудит**: 14 проверок с разделением «Факт / Требует проверки / Ограниченная точность», сводный отчёт.
* **Журналы безопасности DC** (4740, 4625, 4720, 4728…) с анализом источников блокировок.
* **Массовые операции**: CSV-импорт с предпросмотром, план с причинами пропусков, **Dry Run**, отдельное подтверждение,
  ограничение скорости, обработка ошибок по объектам, отчёт.
* **LDAP Explorer** (только чтение): конструктор фильтров с экранированием, история, избранное, справочник атрибутов.
* **Инструменты**: генератор паролей, DNS/LDAP/LDAPS-проверки, WhoAmI, проверка членства, сравнение пользователей,
  групп и OU. **Отчёты** CSV/XLSX/HTML с датой, доменом, DC, критериями и ограничениями данных.
* Безопасность: режим «только чтение» по умолчанию, проверка прав перед изменением, подтверждения, защита
  привилегированных объектов, журнал операций приложения, маскирование секретов, Windows Credential Manager по согласию.
* Тёмная и светлая темы, фоновое выполнение с отменой, сохранение столбцов, контекстные меню, уведомления.
* **Демо-режим** без контроллера домена: `ADAdminToolkit.exe --demo`.

## Установка для пользователей

Передавайте пользователям один файл **`ADAdminToolkit-Setup-<версия>.exe`** (артефакт `ADAdminToolkit-Setup` в GitHub
Actions или `build_installer.bat`). Мастер установки позволяет выбрать папку и создать ярлык на рабочем столе; без прав
администратора можно установить «только для меня». Python не нужен. Подробнее — [docs/BUILD.md](docs/BUILD.md#установщик).

## Быстрый старт

```bat
:: сборка EXE (нужен только на машине сборки Python 3.12 x64)
build_exe.bat
dist\ADAdminToolkit\ADAdminToolkit.exe --demo

:: из исходников
py -3.12 -m venv .venv && .venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python main.py
.venv\Scripts\python -m pytest -q tests
```
