# AD Admin Toolkit — руководство пользователя

## 1. Запуск и подключение

1. Запустите `ADAdminToolkit.exe` (установка Python не требуется). Откроется окно **«Подключение к Active Directory»**.
2. Заполните параметры:
   * **LDAP-сервер / DC** — FQDN контроллера (например, `dc01.company.local`). Имя должно совпадать с сертификатом.
   * **Режим безопасности** — LDAPS (636, рекомендуется), StartTLS (389) или LDAP без шифрования (только Kerberos).
   * **Base DN** — можно оставить пустым: будет определён автоматически.
   * **Сертификат ЦС (PEM)** — если корневой сертификат ЦС домена не установлен в Windows.
   * **Способ аутентификации** — простая (UPN `administrator@company.local` или DN), NTLM (`COMPANY\administrator`)
     или Kerberos с текущими учётными данными Windows (без пароля).
   * **Тайм-ауты**, **размер страницы**, **число попыток переподключения**.
   * **«Только чтение»** — включено по умолчанию.
3. Нажмите **«Проверить подключение»**: по шагам проверяются DNS, TCP-порт, TLS-сертификат, аутентификация, чтение
   каталога и права учётной записи. Результаты — реальные, с подробностями ошибок.
4. **«Подключиться»**. Профиль сохраняется без пароля. Пароль можно сохранить только в Диспетчере учётных данных
   Windows, отметив соответствующий флажок.
5. **Демо-режим** (кнопка в окне подключения или `ADAdminToolkit.exe --demo`) — вымышленный домен `demo.local` в памяти
   для знакомства с интерфейсом и обучения; изменения не выходят за пределы программы.

Верхняя панель показывает состояние (Подключено / Переподключение / Нет связи), домен, DC, учётную запись,
шифрование (🔐 TLS или ⚠ «Не зашифровано»), переключатель **«Только чтение / Изменения разрешены»**, глобальный поиск
(Ctrl+F). Внизу — индикатор выполнения, кнопка **«Отменить»** и время последнего успешного обмена с DC.

## 2. Главная

Статистика домена: пользователи (активные/отключённые/заблокированные/с истёкшим паролем/PNE/неактивные/новые),
компьютеры (всего/отключённые/неактивные), группы. Значения с «≈» — приблизительные (lastLogonTimestamp).
Показаны время сбора и ошибки сбора. Щелчок по карточке открывает соответствующий список.

## 3. Пользователи

* **Представления**: все, активные, отключённые, заблокированные, срок УЗ истёк / скоро истечёт, пароль истёк / скоро
  истечёт, смена пароля при входе, Password Never Expires, User Cannot Change Password, PASSWD_NOTREQD, неактивные,
  нет данных о входе, неполные атрибуты, недавно созданные, привилегированные.
* **Поиск** по ФИО, логину, email, должности, отделу, табельному номеру, DN; фильтр по OU, отделу и должности;
  период для неактивных/истекающих/новых. Фильтры можно **сохранять**.
* Таблица: сортировка по столбцу, быстрый фильтр, выбор столбцов (меню «Столбцы» или правый щелчок по заголовку),
  ширина и порядок столбцов запоминаются. Цвет: серый — отключена, красный — заблокирована, жёлтый — истёк срок.
* **Контекстное меню**: карточка, копирование DN/логина/UPN, включение/отключение, разблокировка, сброс пароля,
  смена пароля при входе, срок действия, изменение атрибутов, создание по образцу, перемещение, добавление в группу,
  обработка увольнения, сравнение двух выделенных пользователей.
* **Карточка пользователя**: общие сведения, учётная запись (блокировка, сроки, флаги, запрет смены пароля по ACL),
  группы прямые и косвенные с путём вложенности, все атрибуты, «Точный последний вход» (опрос всех DC).
* **Создание пользователя**: по шаблону (OU, атрибуты, группы, шаблон логина с транслитерацией) или копированием
  разрешённых атрибутов и групп существующего пользователя (привилегированные группы не копируются).
* Операция над несколькими выделенными объектами всегда открывает **мастер массовых операций**.

## 4. Компьютеры

Представления: все, включённые, отключённые, неактивные, нет данных о входе, устаревшие ОС, серверы, рабочие станции,
контроллеры домена, недавно созданные, без ОС. Карточка компьютера: данные каталога и отдельная вкладка **«Сетевая
доступность»** (DNS, ping, TCP 135/445/3389/5985/5986). LDAP не показывает, включён ли компьютер сейчас.
«Проверить доступность» — параллельная проверка выделенных компьютеров; «Список для диагностики» — экспорт.
Учётные записи контроллеров домена не отключаются и не перемещаются через приложение.

## 5. Группы

Поиск по имени/описанию, фильтр по области (глобальная, локальная в домене, универсальная, встроенная) и типу
(безопасности/распространения), «только привилегированные». Нижняя панель — участники выбранной группы (прямые или с
учётом вложенности). Карточка группы: участники, косвенное членство с путём, дерево вложенности (циклы помечаются ⟳),
группы-родители. Функции: пустые группы (с учётом primaryGroupID), состав привилегированных групп, сравнение двух
групп, пользователи без стандартных групп (правила задаются в Настройках), создание группы.
**Привилегированные группы** отмечены ⚠ и красным; изменение их состава требует ввода имени группы.

## 6. Структура OU

Дерево OU и контейнеров с количеством пользователей, компьютеров, групп и общим числом вложенных объектов; пустые OU
выделены серым. Справа — объекты выбранного OU (с вложенными или без). Функции: пустые OU, создание OU, удаление
**только пустого** и незащищённого OU (ввод имени), перемещение выделенных объектов (целевое OU проверяется:
существование, отсутствие конфликта имени, права), экспорт структуры, **снимок** для последующего сравнения
(Инструменты → «Сравнение OU»).

## 7. Аудит и диагностика

Выберите проверки и нажмите **«Запустить аудит»**. Находки имеют критичность и характер: **Факт**, **Требует проверки**
(индикатор, не доказательство), **Ограниченная точность**. Проверки: отключённые/заблокированные/неактивные
пользователи, неактивные компьютеры, PNE, отсутствие срока УЗ в OU с обязательным сроком, члены привилегированных
групп, необычные членства (вложенные группы в критичных группах, циклы, orphaned adminCount), неполные атрибуты,
подозрительные флаги (PASSWD_NOTREQD, без Kerberos preauth, обратимое шифрование, неограниченное делегирование, SPN у
админов, Guest, возраст пароля krbtgt, «уволен» но включён), устаревшие ОС, недавно созданные объекты, доступность DC
(DNS, 389/636/88, TLS-сертификат), корректность подключения (шифрование, права учётной записи, MachineAccountQuota,
политика блокировки и паролей). Экспорт сводного отчёта — XLSX/CSV/HTML.

## 8. Журналы безопасности

Чтение журнала Security контроллеров домена через `wevtutil` с текущими учётными данными Windows. Выберите DC, группы
событий (блокировки, управление УЗ, изменения групп, компьютеры, критичные, входы, Kerberos/NTLM) или коды вручную,
период, пользователя, минимальную критичность и лимит. Вкладка **«Анализ блокировок (4740)»** группирует блокировки по
пользователю и компьютеру-источнику. Требования показаны на странице; при недоступности ошибка указывается для
каждого DC.

## 9. Массовые операции

1. Выберите операцию (отключить, включить, разблокировать, добавить в группу, удалить из группы, переместить в OU,
   подготовить список для сброса паролей) и тип объектов.
2. Загрузите объекты: **импорт CSV** (разделитель и кодировка UTF-8/Windows-1251 определяются автоматически,
   предварительный просмотр, выбор столбца идентификатора) или список/выделение из таблиц.
3. **«Проверить и построить план»** — для каждого объекта: найден ли, текущее состояние, планируемое изменение,
   причина пропуска (уже в нужном состоянии, привилегированная УЗ, DC, дубликат) или ошибки (не найден, неоднозначно,
   нет прав).
4. **Dry Run** (включён по умолчанию) — моделирование с записью в журнал без изменений AD.
5. Реальное выполнение требует режима изменений и ввода фразы `ВЫПОЛНИТЬ N`; привилегированная целевая группа —
   отдельного подтверждения её именем. Объекты обрабатываются независимо, со скоростью из настроек; операцию можно
   отменить. Итоговый отчёт — кнопка «Экспорт…».

**Увольнение сотрудников** (вторая вкладка): шаблоны (отключить, записать «Уволен {date} {ticket}», удалить из групп
кроме исключений, переместить в OU, срок действия = сегодня, случайный пароль, очистить руководителя, скрыть из
адресной книги). Поиск кандидатов по маркеру в описании или по истёкшему сроку. **«Подготовить план»** не меняет AD —
план можно выгрузить как список для отключения. Привилегированные учётные записи исключаются.

## 10. LDAP Explorer (только чтение)

Конструктор фильтров (тип объекта, условия с операторами «равно/содержит/начинается/≥/≤/битовое И/ИЛИ/рекурсивное
членство», AND/OR), примеры (отключённые пользователи, заблокированные, компьютеры и др.), редактор фильтра с проверкой
синтаксиса, Base DN, область, атрибуты, лимит. Результаты — таблица с выбранными атрибутами и панель всех атрибутов
объекта. История запросов и избранное сохраняются. Справочник атрибутов — двойной щелчок добавляет атрибут в запрос.

## 11. Инструменты

Генератор паролей (длина, наборы, исключение похожих символов, энтропия; копирование с автоочисткой буфера), DNS
(SRV-записи домена), LDAP/LDAPS/StartTLS (порт, RootDSE, сертификат), разрешение имени, порты DC, доступность узла,
текущий пользователь (WhoAmI, группы, права), проверка членства (прямое/основная группа/вложенное) и все группы объекта
с путями, сравнение пользователей (атрибуты, группы), сравнение групп, сравнение структуры OU по снимкам,
справочник LDAP-атрибутов.

## 12. Отчёты

Готовые отчёты: отключённые, заблокированные, неактивные пользователи (период), неактивные компьютеры, PNE, состав
привилегированных групп, пользователи и группы, компьютеры по OU и ОС, неполные атрибуты, общий отчёт о состоянии домена;
результаты массовых операций — из мастера. **«Отчёт для руководителя»** — HTML со сводными показателями.
Каждый отчёт содержит дату, домен, DC, автора, критерии и ограничения данных. CSV — UTF-8 с BOM, разделитель «;»,
защита от формульных инъекций.

## 13. Журнал операций

Все операции, выполненные через приложение: время, пользователь Windows, учётная запись LDAP, операция, объект,
результат (успешно/ошибка/Dry Run/пропущено/отменено), ошибка, параметры, номер пакета. **Это не полный аудит AD** —
для расследований используйте журналы контроллеров домена.

## 14. Настройки

Тема (тёмная/светлая), задержка поиска, лимит строк, очистка буфера, периоды неактивности/истечения/«новых»,
обязательные атрибуты, стандартные группы, дополнительные привилегированные группы, OU с обязательным сроком УЗ,
правила устаревших ОС, лимиты и скорость массовых операций, тайм-ауты, UPN-суффикс.

## 15. Частые проблемы

| Сообщение | Решение |
|---|---|
| «Сертификат контроллера домена не прошёл проверку» | Подключайтесь по FQDN из сертификата; установите корневой сертификат ЦС или укажите PEM-файл |
| «Контроллер требует подписывания/шифрования LDAP» | Используйте LDAPS или StartTLS |
| «Неверное имя пользователя или пароль» / «Учётная запись заблокирована» | Проверьте учётные данные; коды AD (52e, 775, 532…) переводятся в понятный текст |
| «Недостаточно прав…» | Делегируйте права на OU (см. AD_PERMISSIONS.md) |
| «Значение атрибута изменилось с момента чтения» | Объект изменён другим администратором — обновите и повторите |
| Журналы: «RPC недоступен» / «Отказано в доступе» | Откройте RPC на DC, добавьте учётную запись в Event Log Readers |
