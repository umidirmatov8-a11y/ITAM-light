# Функции: через LDAP и через дополнительные механизмы Windows

## Работают через LDAP (ldap3)

Подключение (LDAPS/StartTLS, Simple/NTLM/Kerberos), обнаружение домена, статистика, все представления пользователей,
компьютеров и групп, состав и вложенность групп, дерево OU и счётчики, аудит (кроме сетевых проверок DC), LDAP Explorer,
отчёты, все операции изменения (включение/отключение, разблокировка, сброс пароля, атрибуты, срок действия,
перемещение, членство в группах, создание пользователей/групп/OU, удаление пустого OU), массовые операции,
обработка уволенных, точный lastLogon (LDAP-запросы к каждому DC), сравнение пользователей/групп, снимки OU.

## Требуют дополнительных механизмов

| Функция | Механизм | Требования | Поведение при недоступности |
|---|---|---|---|
| Журналы безопасности DC (4740, 4625, 4720…) | `wevtutil.exe qe Security /r:<DC>` (встроен в Windows), текущие учётные данные Windows | Windows 10/11; TCP 135 + динамические RPC-порты до DC; правило брандмауэра «Удалённое управление журналом событий (RPC)»; членство в **Event Log Readers** на DC; политика аудита DC | Модуль сообщает, какое требование не выполнено, по каждому DC; данные не имитируются |
| Kerberos (текущий пользователь Windows) | SASL GSSAPI через `winkerberos` (SSPI) | компьютер в домене или `runas /netonly`; SPN `ldap/<FQDN DC>` | ошибка подключения с пояснением |
| Хранение пароля | Windows Credential Manager (`keyring` → WinVault) | явное согласие пользователя | флажок недоступен, пароль не сохраняется |
| ICMP ping | `ping.exe` | — | «Н/Д»; результат дополняется TCP-проверками |
| DNS SRV-записи | `dnspython` (DNS-серверы из настроек Windows) | доступ к DNS-серверу | ошибка «тайм-аут/NXDOMAIN» как есть |
| Доступность компьютера | TCP 135/445/3389/5985/5986 + DNS + ping | сетевой доступ | фактический результат с тайм-аутом |

PowerShell в приложении **не используется**: для журналов событий выбран штатный `wevtutil.exe`, которому не нужны
модуль ActiveDirectory/RSAT, PowerShell Remoting (WinRM) и передача пароля в командной строке.
Если требуется запуск под другой учётной записью: `runas /netonly /user:ДОМЕН\учётка ADAdminToolkit.exe`.
