# AgentLoop — команда из трёх ИИ-агентов

Вы пишете задачу — над ней по кругу работают три агента:

```
задача ─► [1. Промпт-инженер] ─► промпт ─► [2. Исполнитель] ─► результат ─► [3. Проверяющий]
                 ▲                                                               │
                 └──────────── не принято: замечания и рекомендации ◄────────────┤
                                                                     принято ─► вам
```

1. **Промпт-инженер** превращает вашу задачу в подробный, правильный промпт (роль, требования, формат, критерии качества).
2. **Исполнитель** выполняет этот промпт.
3. **Проверяющий** сверяет результат с *исходной* задачей и выставляет оценку 0–10.
   Принято — результат показывается вам. Не принято — замечания уходят обратно промпт-инженеру,
   он переписывает промпт, и круг повторяется (по умолчанию до 3 кругов; если ни один вариант
   не принят, показывается лучший по оценке с пометкой ⚠).

Весь ход работы (каждый промпт, результат и заключение проверяющего) виден на вкладке
«Ход работы агентов» и сохраняется кнопкой «Сохранить отчёт…».

## Установка — всё уже внутри

Скачайте из GitHub Actions (workflow **AgentLoop (Windows)** → артефакт `AgentLoop-Setup-windows`),
распакуйте и запустите `AgentLoop-Setup.exe`. Файлы `AgentLoop-Setup-*.bin` должны лежать рядом с ним:
модель весит около 2 ГБ, поэтому установщик разбит на части.

Установщик кладёт в `%LOCALAPPDATA%\Programs\AgentLoop`:

* `AgentLoop.exe` — программа (Python не нужен);
* `runtime\` — движок [llama.cpp](https://github.com/ggml-org/llama.cpp) (`llama-server.exe`, версия CPU x64);
* `models\qwen2.5-3b-instruct-q4_k_m.gguf` — веса
  [Qwen2.5-3B-Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF) с Hugging Face (квантизация Q4_K_M);

и создаёт ярлык **AgentLoop на рабочем столе** и в меню «Пуск». Ничего дополнительно ставить не нужно:
ни Ollama, ни Python, ни API-ключей; интернет после установки не нужен.

При первом запуске модель загружается в память 10–30 секунд, движок работает в фоне без окон и закрывается
вместе с программой. Нужно около 4 ГБ свободной оперативной памяти; видеокарта не требуется.

Лицензия весов Qwen2.5-3B — Qwen Research License (некоммерческое использование). Для коммерческого
использования соберите программу с моделью под Apache 2.0, например `Qwen/Qwen2.5-1.5B-Instruct-GGUF`
или `Qwen/Qwen2.5-7B-Instruct-GGUF` (см. «Сборка»).

### Другие модели

В «Настройках» → «Встроенная модель» → «Папка моделей» можно положить любой файл `.gguf`
(например, с huggingface.co: ищите репозитории с `GGUF` в названии) и выбрать его в списке.

## Какая нейросеть работает

По умолчанию — **встроенная модель** (см. выше). В «Настройках» можно переключиться на:

* **Ollama** — если он у вас уже установлен (модели `qwen2.5:0.5b` … `qwen2.5:7b`, `llama3.2:3b`, `gemma3:4b`,
  кнопка «Скачать модель»);
* **Claude API** — облако, модель `claude-opus-5-5`, нужен платный ключ с https://console.anthropic.com
  (в настройках или в переменной `ANTHROPIC_API_KEY`).

Маленькие модели часто ошибаются, и проверяющий (такая же маленькая модель) тоже может пропустить ошибку,
поэтому для серьёзных задач берите модель 7B и больше или Claude API.

Настройки хранятся в `%APPDATA%\AgentLoop\config.json` (ключ Claude — открытым текстом, не передавайте этот файл).

## Консольный режим

```
AgentLoop.exe --task "Напиши SQL-запрос: топ-5 клиентов по сумме заказов" --report report.md
AgentLoop.exe --task "..." --provider local --model другая-модель.gguf --iterations 2
AgentLoop.exe --task "..." --provider ollama --model qwen2.5:0.5b
```

Модель Ollama скачивается автоматически, если её нет. Код выхода: `0` — результат принят, `1` — не принят (выведен лучший), `2` — ошибка.
Собранный exe — оконный, поэтому вывод в консоль удобнее получать при запуске из исходников: `python main.py --task "..."`.

## Сборка из исходников (Windows)

```powershell
cd agent-loop
.\build.ps1        # тесты, скачивание llama.cpp и весов (с проверкой SHA-256), AgentLoop.exe, установщик
.\build.ps1 -ModelRepo Qwen/Qwen2.5-7B-Instruct-GGUF -ModelFile qwen2.5-7b-instruct-q4_k_m.gguf
```

Нужен Python 3.12 и [Inno Setup 6](https://jrsoftware.org/isinfo.php) для установщика.
Запуск без сборки: `pip install -r requirements.txt`, `python scripts/fetch_assets.py`, `python main.py`.
Тесты: `pytest`.

## Устройство

| Файл | Что делает |
|---|---|
| `app/pipeline.py` | цикл агентов, системные промпты всех трёх агентов, разбор вердикта |
| `app/local_runtime.py` | встроенная модель: запуск и остановка `llama-server`, запросы к нему |
| `app/providers.py` | подключение к Claude API и Ollama |
| `scripts/fetch_assets.py` | скачивание llama.cpp и весов с Hugging Face для сборки |
| `app/gui.py` | окно (Tkinter) |
| `app/config.py` | настройки |
| `app/report.py` | отчёт в Markdown |

Чтобы изменить поведение агентов, правьте `PROMPT_ENGINEER_SYSTEM`, `EXECUTOR_SYSTEM` и `VERIFIER_SYSTEM` в `app/pipeline.py`.
