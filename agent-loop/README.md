# AgentLoop — команда из трёх ИИ-агентов

Вы пишете задачу — над ней по кругу работают три агента:

```
задача ─► [1. Промпт-инженер] ─► промпт ─► [2. Исполнитель] ─► результат ─► [3. Проверяющий]
                 ▲                                                               │
                 └──────────── не принято: замечания и рекомендации ◄────────────┤
                                                                     принято ─► вам
```

1. **Промпт-инженер** превращает вашу задачу в подробный, правильный промпт (роль, требования, формат, критерии качества).
2. **Исполнитель** выполняет этот промпт.
3. **Проверяющий** сверяет результат с *исходной* задачей и выставляет оценку 0–10.
   Принято — результат показывается вам. Не принято — замечания уходят обратно промпт-инженеру,
   он переписывает промпт, и круг повторяется (по умолчанию до 3 кругов; если ни один вариант
   не принят, показывается лучший по оценке с пометкой ⚠).

Весь ход работы (каждый промпт, результат и заключение проверяющего) виден на вкладке
«Ход работы агентов» и сохраняется кнопкой «Сохранить отчёт…».

## Установка

Скачайте из GitHub Actions (workflow **AgentLoop (Windows)** → артефакт `AgentLoop-windows`):

* `AgentLoop-Setup.exe` — обычный установщик (ярлыки в «Пуске» и на рабочем столе, удаление через «Программы»);
* `AgentLoop.exe` — портативная версия, запускается без установки.

Python на компьютере не нужен.

## Какая нейросеть работает

Откройте **Настройки**:

* **Claude API** (по умолчанию, модель `claude-opus-5-5`) — нужен API-ключ с https://console.anthropic.com.
  Ключ вводится в настройках или берётся из переменной окружения `ANTHROPIC_API_KEY`.
  «Усилие» (effort) регулирует глубину размышлений и расход токенов: `low` дешевле и быстрее, `max` — тщательнее.
* **Ollama** — бесплатные локальные модели без интернета. Установите https://ollama.com,
  выполните `ollama pull qwen2.5:14b` (или другую модель) и укажите её имя в настройках.

Настройки хранятся в `%APPDATA%\AgentLoop\config.json` (ключ — открытым текстом, не передавайте этот файл).

## Консольный режим

```
AgentLoop.exe --task "Напиши SQL-запрос: топ-5 клиентов по сумме заказов" --report report.md
```

Код выхода: `0` — результат принят, `1` — не принят (выведен лучший), `2` — ошибка.
Собранный exe — оконный, поэтому вывод в консоль удобнее получать при запуске из исходников: `python main.py --task "..."`.

## Сборка из исходников (Windows)

```powershell
cd agent-loop
.\build.ps1            # тесты + dist\AgentLoop.exe + installer\Output\AgentLoop-Setup.exe (если установлен Inno Setup 6)
```

Запуск без сборки: `pip install -r requirements.txt` и `python main.py`. Тесты: `pytest`.

## Устройство

| Файл | Что делает |
|---|---|
| `app/pipeline.py` | цикл агентов, системные промпты всех трёх агентов, разбор вердикта |
| `app/providers.py` | подключение к Claude API и Ollama |
| `app/gui.py` | окно (Tkinter) |
| `app/config.py` | настройки |
| `app/report.py` | отчёт в Markdown |

Чтобы изменить поведение агентов, правьте `PROMPT_ENGINEER_SYSTEM`, `EXECUTOR_SYSTEM` и `VERIFIER_SYSTEM` в `app/pipeline.py`.
